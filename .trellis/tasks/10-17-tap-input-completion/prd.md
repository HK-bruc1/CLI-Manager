# Tap 对话命令菜单与文件引用

## 目标与授权

V1.4.5：在现有 Tap 对话输入框集成 Codex/Claude 的原生命令菜单与 @ 项目文件选择，复用当前 PTY 和文件接口。用户已批准创建并实现任务，反馈三项问题后再次验证，并授权提交、推送及清理不必要改动。

## 最终要求

- 行首输入 / 或无参数的命令前缀，在对话页内打开同一 CLI 的原生面板。菜单、已加载 skills、插件与 /mcp 后续操作由真实 CLI 提供，不维护静态候选表。
- 前缀仅输入一次，不附加回车、不自动重试；失败保留原草稿。原生交互提供方向键、Tab、Esc、Enter 和手机键盘入口。
- 在 CLI 中完成或取消并清空未发送内容后返回对话；返回按钮只关闭视图。对话和同一终端保持挂载，不改持久视图偏好，不迁移 ACP。
- 词首 @ 浏览当前注册项目/Worktree 文件；目录下钻、返回上级与文件名/相对路径搜索，引用保留中文、空格及光标前后文本，不上传正文。
- 使用主机实际的 file.management 能力，file.list/file.search 是操作名。候选每次重新唤起都有独立交互身份，不能继承旧关闭状态或选中项。
- 文件候选支持方向键、Enter/Tab、Esc 和点击；空/加载列表不误发送，IME 和长按回车受保护。
- 断线、隐藏、切账号/设备/会话/Worktree 后丢弃旧结果及回调；单请求串行、去抖和有界候选。
- 双语、深浅主题和手机软键盘；桌面拥有终端网格时只滚动，不为面板 resize PTY。
